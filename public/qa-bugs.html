// BUG-001 · 엘리프 무한 복제
BUG-001 CRITICAL · P1
왕사탕 최대 보유 상태에서 엘리프 중복 획득 가능
환경 Android / iOS · 전 기기 발생일 2024-08-29 상태 [ FIXED ]
재현 절차
왕사탕을 최대 보유량까지 수집한다.
왕사탕 → 엘리프 교환 가능한 보상 수령 대기 상태를 만든다.
엘리프 수령 버튼을 빠르게 연속으로 탭한다.
수령 완료 후 엘리프 보유량을 확인한다.
기대 결과
수령 1회분 엘리프만 지급. 중복 요청은 서버에서 무시된다.
실제 결과
탭 횟수만큼 엘리프 중복 지급. 최대 악용 사례 5,521회 반복 수령 확인 (3,864,700 엘리프 상당).
영향도
게임 내 재화 경제 시스템 붕괴 — 정상 플레이어와의 형평성 심각 훼손 악용 유저 12명 영구 제재 처리로 커뮤니티 신뢰도 손상 회수 불가능한 재화 배포로 장기 밸런스 패치 비용 발생
[ DEV ] 개발자 관점 원인 추론
엘리프 지급 API가 요청 수신 시 서버 측 중복 처리(idempotency) 검증 없이 즉시 실행된 것으로 추정. 왕사탕 최대치 상태에서 수령 요청이 들어오면 클라이언트 측 UI만 잠기고, 서버는 들어오는 요청을 그대로 처리하는 구조로 보임.

올바른 대응: 지급 요청에 transactionId 부여 후 서버에서 처리 여부 조회 → 이미 처리된 요청이면 무시. 또는 왕사탕 최대치 도달 여부를 지급 직전 서버에서 재검증.

// BUG-002 · 친밀도 스탯 누적 오류
BUG-002 HIGH · P1
친밀도 레벨업 시 치명타 스탯 약 5.5배 누적 증가
환경 Android / iOS · 전 기기 발생일 2023-10-04 수정 완료 2023-10-05 (이틀 이내) 상태 [ FIXED ]
재현 절차
특정 캐릭터의 친밀도 레벨업 전 치명타 관련 스탯 수치를 기록한다.
해당 캐릭터 친밀도를 1레벨 올린다.
레벨업 직후 치명타 스탯 수치를 확인한다.
예상 증가분과 실제 증가분을 비교한다.
기대 결과
치명타 스탯이 해당 레벨의 증가분(delta)만큼 정확히 상승한다.
실제 결과
치명타 스탯이 의도치 않게 약 5.5배 누적 증가. 레벨이 높아질수록 오차 폭이 더 커짐.
영향도
특정 캐릭터 전투력 비정상 과대 적용 → 콘텐츠 난이도 급락 친밀도 육성 투자 유저와 미투자 유저 간 밸런스 파괴 수정 후 스탯 정상화 시 기존 클리어 콘텐츠 재도전 불가 상황 발생 가능
[ DEV ] 개발자 관점 원인 추론
친밀도 레벨업 이벤트 핸들러에서 스탯 적용 방식이 delta가 아닌 누적값 재가산으로 구현된 것으로 추정.

올바른 구현: newStat = prevStat + (bonus[N] - bonus[N-1])
추정 실제 구현: newStat = prevStat + bonus[N]

이 경우 레벨업마다 이전 레벨까지의 보너스가 중복 가산되어, 레벨이 높아질수록 오차가 선형이 아닌 누적 증폭됨. 또는 레벨업 이벤트 핸들러가 다중 트리거되는 구조일 가능성도 있음.

두 버그의 공통점
두 케이스 모두 "경계 조건에서 서버 검증이 빠진" 패턴입니다. BUG-001은 최대 보유량 도달 시 지급 API 재검증 누락, BUG-002는 스탯 계산 공식의 적분/미분 혼동.

개발 관점에서 두 버그 모두 단위 테스트(Unit Test)가 있었다면 배포 전에 잡혔을 가능성이 높습니다. QA 입장에서는 경계값 테스트 케이스 — 최대치, 최소치, 레벨 전환점 — 를 체크리스트에 필수 항목으로 넣는 것이 핵심입니다.
개발자 출신 QA의 강점
원인 레벨의 분석이 가능한 버그 리포트는 개발팀의 수정 시간을 단축합니다. "이렇게 됩니다"가 아닌 "왜 이렇게 됐는지, 어디를 보면 되는지"까지 담긴 리포트가 QA의 실질적 가치입니다.
